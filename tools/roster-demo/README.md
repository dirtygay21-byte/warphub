# Демо: коды доступа к Roster Builder на своём компьютере

Запускает WarpHub в браузере **без Telegram, базы данных и настоящего сервера**. Маленький локальный сервер
изображает бэкенд: код «присылает бот» — он печатается в окне консоли. Можно по очереди быть
админом и обычными игроками и пройти весь путь: создать код → ввести → открыть Roster Builder → закрыть доступ.

Нужен **Node.js 22** (https://nodejs.org, версия LTS).

## Запуск

Из папки репозитория (`warphub`):

```bash
cd client
npm install            # один раз
npm run build:demo     # собирает client/dist-demo (после каждого обновления кода)
cd ..
node tools/roster-demo/server.mjs
```

Открыть **http://localhost:5050** — лучше в режиме телефона (Chrome: F12 → значок телефона, Ctrl+Shift+M).

## Что попробовать

Слева на экране вкладка **«ДЕМО · ЕГОР ⇄»** — нажатие переключает пользователя:
Егор (админ) → Иван (игрок) → Анна (игрок) → снова Егор.

1. **Егор:** Админ → вкладка «Ростеры» → «Создать код доступа». Код появится в окне консоли.
2. **Иван:** Профиль → «Есть код доступа?» → ввести код. Откроется Roster Builder, в профиле появится кнопка.
   Попробуйте сначала неверный код — увидите счётчик попыток (после 5 ошибок — блок на час).
3. Тот же код ещё раз (например, у **Анны**) уже не сработает — он одноразовый.
   Открыть адрес `/roster` напрямую без доступа тоже нельзя — вернёт в профиль.
4. **Егор:** во вкладке «Ростеры» видно, кто открыл доступ, и кнопка «Закрыть». После неё у Ивана доступа нет.

Кнопка Telegram «Назад» в демо — вкладка «← НАЗАД» слева.

## Чем демо отличается от настоящего

- Пользователи ненастоящие, вход без проверки Telegram. Другие разделы (записи, новости) пустые.
- Всё хранится в памяти: перезапуск сервера (Ctrl+C и снова `node …`) обнуляет коды и доступы.
  Ростеры хранятся в браузере, у каждого демо-пользователя свои.
- Правила кодов те же, что на бэкенде: 4 цифры, одноразовый, 24 часа, 5 ошибок в час на человека.
